# Mapty — Workout Tracker

A workout tracking web application built with JavaScript and Leaflet.

## About the Project

Mapty allows users to record their running and cycling workouts directly on an interactive map. Each workout is displayed on the map and saved in the browser, so the data remains available after reloading the page.

## Features

- Add running workouts by clicking on the map.
- Add cycling workouts by clicking on the map.
- Enter workout distance and duration.
- Calculate running pace and cycling speed automatically.
- Record running cadence and cycling elevation gain.
- Display workout locations on an interactive map.
- Save workouts in the browser using Local Storage.
- Navigate to a workout location by selecting it from the list.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Leaflet.js
- OpenStreetMap
- Browser Local Storage

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Bunyaka/mapty-workout-tracker.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

The application may ask for permission to access your location.
